# Haruhi Official Documentation

This is the official documentation (documents, files, & folders) of the Haruhi Engine. The documentation is supported in multiple spoken languages, allowing the engine to be globally accessible.

## Available Languages

- English (en) : Primary language
- Spanish (es) : Parcialmente, el Español que se usa es Español Mexicano
- German (de) : Teilweise, wird allgemeines Deutsch verwendet
